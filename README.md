# Pharmacy POS

Compact pharmacy point-of-sale interface prototype for order terminals and a cashier station.

## Open in VS Code

1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

This repository currently contains a front-end prototype with sample data. It does not yet include the ASP.NET Core application, PostgreSQL database, authentication, or production transaction processing.
